# Casas de Hogwarts

SPA em React que lista as casas de Hogwarts e traz um quiz para descobrir a sua.

**API utilizada:** [Wizard World API](https://wizard-world-api.herokuapp.com/swagger/index.html)

## Estrutura

```
src/
├── components/   # Casa.jsx, Quiz.jsx
├── services/     # hogwartsService.js (chamadas à API)
├── data/         # perguntas do quiz
└── assets/
```

## Como rodar

```bash
npm install
npm run dev
```

Outros scripts: `npm run build`, `npm run lint`.
